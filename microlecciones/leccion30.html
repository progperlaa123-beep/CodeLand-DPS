🕵️‍♂️ Actividad 1: Code Detective Evaluar

Contexto: Un sistema de escaneo busca el identificador de un intruso en un vector de 1000 celdas desordenadas. El elemento objetivo se localiza en la última celda (índice 999).

Pregunta: Basándote en la eficiencia temporal del peor de los casos en búsquedas lineales, ¿cuál es la conclusión correcta?

  • El algoritmo ejecutará exactamente 1 comparación debido al uso de memoria RAM dinámica.
  • El algoritmo realizará un recorrido lineal forzoso ejecutando las 1000 comparaciones de forma secuencial celda por celda.
  • Se generará un desbordamiento físico de memoria al evaluar el último índice del vector.
🕵️‍♂️ Actividad 2: Code Detective Evaluar

Contexto: El radar de la estación utiliza una cuadrícula matricial de 3x3 indexada en base cero. Analiza el recorrido ejecutado por las siguientes estructuras repetitivas anidadas.

Para i = 0 Hasta 2 Con Paso 1 Hacer
    Para j = 0 Hasta 2 Con Paso 1 Hacer
        Si i == 1 Entonces
            radar[i][j] = 9
        FinSi
    FinPara
FinPara

Pregunta: ¿Qué zona geográfica de la matriz de datos fue modificada con el valor numérico 9 tras concluir las iteraciones?

  • Toda la primera columna vertical del radar.
  • La fila intermedia horizontal completa (Fila 1).
  • Únicamente la celda central localizada en la coordenada [1][1].
🛠️ Actividad 3: Debug Pro Evaluar

Contexto: Un algoritmo de telemetría médica intenta aislar los valores de la diagonal principal de una matriz cuadrada mediante ciclos anidados redundantes, consumiendo excesivos ciclos de reloj de la CPU.

// Código defectuoso por ineficiencia temporal
Para i = 0 Hasta N-1 Hacer
    Para j = 0 Hasta N-1 Hacer
        Si i == j Entonces
            Imprimir matriz[i][j]
        FinSi
    FinPara
FinPara

Pregunta: ¿Cuál es la refactorización lógica óptima que extrae la diagonal principal eliminando por completo el desperdicio del ciclo anidado horizontal?

  • Reemplazar toda la estructura por un único ciclo simple: `Para i = 0 Hasta N-1 Hacer Imprimir matriz[i][i] FinPara`.
  • Cambiar la condición lógica a `Si i != j` para forzar una búsqueda lineal invertida.
  • Transponer de forma recursiva la matriz entera antes de mandar a consola los datos.
🛠️ Actividad 4: Debug Pro Evaluar

Contexto: Un ingeniero júnior entregó un módulo crítico de soporte vital. Aunque el script funciona, su mantenimiento es imposible debido a la violación sistemática de los estándares mundiales de legibilidad de código.

Funcion s(a,b)
Si a>b Entonces
Retornar a
Sino
Retornar b
FinSi
FinFuncion

Pregunta: Desde la perspectiva de las buenas prácticas de desarrollo, ¿cuáles son las omisiones técnicas más graves de este módulo?

  • Carece por completo de sangrado jerárquico (indentación) y utiliza identificadores mudos no mnemotécnicos que destruyen la legibilidad.
  • El algoritmo tiene un error fatal de sintaxis porque la palabra reservada 'Sino' no pertenece a la programación estructurada.
  • Usa funciones con retorno en lugar de procedimientos globales vacíos.
🚀 Actividad 5: MiniProjects Crear

Desafío de Cierre: Diseña la arquitectura de un motor de procesamiento de datos espaciales. Este debe recibir una matriz de coordenadas de asteroides, realizar una transposición para reorientar los ejes vectoriales y aplicar una búsqueda secuencial limpia controlada por una bandera para localizar una firma térmica exótica.

Pregunta: ¿Qué secuencia de pasos lógicos garantiza el éxito técnico y la escalabilidad de este proyecto integrador?

  • Utilizar variables globales de una sola letra, transponer mezclando filas de forma aleatoria y omitir las condiciones de parada del ciclo.
  • Declarar la matriz con nombres mnemotécnicos; transponer mediante un bucle anidado ordenado asignando `destino[j][i] = origen[i][j]`; y aplicar una búsqueda lineal sobre la estructura procesada usando una bandera lógica binaria que interrumpa el bucle de inmediato al hallar el objetivo.
  • Evitar el uso de subalgoritmos o modularidad, programando una sola función masiva de mil líneas consecutivas sin comentarios.
