🚀 Contexto de Aplicación Real

Imagina que eres el administrador del inventario de un hangar de naves espaciales. Si para registrar 100 naves crearas 100 variables individuales (`nave1`, `nave2`, ..., `nave100`), tu código sería una pesadilla imposible de leer. En lugar de eso, utilizas una estructura de datos lineal: un Arreglo (Vector). Un arreglo es como un casillero gigante del hangar escolar con un solo nombre general, donde cada compartimento tiene una etiqueta numérica (índice) para guardar y consultar cada nave velozmente mediante bucles.

24. Estructuras de Datos Lineales: Arreglos Unidimensionales (Vectores)

Un arreglo es una estructura de datos homogénea y estática que almacena un conjunto finito de elementos del mismo tipo bajo un único nombre de variable común.

💡 Conceptos Clave y Definiciones Académicas:

  • Arreglo / Vector: Colección ordenada de datos. Homogénea significa que todos sus elementos deben ser del mismo tipo (ej. puros números enteros o puros caracteres texto).
  • Índice de Acceso: Posición numérica que identifica a cada celda del casillero. Dependiendo del lenguaje, el índice inicia en 0 o en 1 (PSeInt por defecto inicia en 1).
  • Dimensión Estática: El tamaño máximo del arreglo debe definirse al crearse y no puede expandirse ni encogerse dinámicamente durante la ejecución del programa.

⚡ Evaluación

¿Qué significa que un Arreglo sea una estructura de datos "Homogénea"?

  • Que todos los elementos almacenados deben ser obligatoriamente del mismo tipo de datos.
  • Que puede mezclar textos, booleanos y funciones de forma aleatoria en el mismo espacio.
  • Que cambia de tamaño automáticamente cada vez que se invoca un ciclo Mientras.

¿Cómo identificamos o accedemos a una posición o celda específica de un Arreglo?

  • Mediante el nombre único de una variable tipo bandera lógica.
  • Invocando una función secundaria de Paso por Referencia.
  • Utilizando un número entero denominado Índice.

En la analogía del hangar, ¿qué elemento representa al "Arreglo" completo?

  • Una sola nave espacial individual volando sola.
  • El conjunto o bloque completo de casilleros compartidos bajo un nombre general de control.
  • La velocidad del cronómetro asíncrono de la misión.

¿Qué implica que un arreglo posea una "Dimensión Estática"?

  • Que su tamaño máximo debe declararse al inicio y no puede modificarse en tiempo de ejecución.
  • Que el arreglo solo funciona cuando la computadora no está ejecutando otros programas.
  • Que borra los datos internos de forma automática cada 5 vueltas.

Si en PSeInt declaras un vector de dimensión 5, ¿cuántos datos del mismo tipo puedes resguardar?

  • Únicamente 1 dato compuesto.
  • Infinitos elementos controlados por bandera.
  • Exactamente hasta 5 elementos ordenados.

¿Qué palabra reservada empleas en PSeInt para fijar formalmente el tamaño máximo de un Vector?

  • DefinirComoEntero
  • Dimension
  • ArregloFijo

¿Qué estructura cíclica de control es la más idónea y utilizada para recorrer de principio a fin los índices de un arreglo?

  • El bucle determinado Para (For) controlado por contador.
  • Un condicional múltiple Según.
  • Una instrucción de salida Abandona Misión.

Si un arreglo se llama `edades` e inicia en el índice 1, ¿cómo asignarías el valor 15 al primer casillero?

  • edades <- 15
  • edades[15] <- 1
  • edades[1] <- 15

¿Qué error lógico severo ocurre al intentar acceder al índice 10 de un vector dimensionado únicamente con tamaño 5?

  • Desbordamiento de memoria o índice fuera de rango (Out of bounds).
  • El vector se duplica a tamaño 20 automáticamente.
  • La variable se transforma directamente en una bandera booleana.

El uso de arreglos nos evita la fatiga estructural en el código de tener que...

  • ...utilizar funciones de paso por valor.
  • ...crear cientos de variables individuales independientes con nombres distintos para guardar datos relacionados.
  • ...escribir comentarios informativos en el pseudocódigo.
