07. Clasificación de Tipos de Datos y Variables

Los tipos de datos determinan la naturaleza de los valores que un programa puede manipular en la memoria RAM, fijando sus límites operacionales y las funciones válidas que se pueden ejecutar con ellos.

💡 Conceptos Clave y Definiciones Académicas:

  • Variables y Constantes: Una variable representa una zona reservada en memoria cuyo valor cambia a lo largo de la ejecución; la constante permanece inalterable desde el inicio hasta el fin.
  • Datos Primitivos Simples: Incluyen los Enteros (valores numéricos sin decimales), Reales o Flotantes (con punto fraccionario) y Caracteres/Cadenas (texto delimitado).
  • Tipo de Dato Booleano: Una estructura binaria fundamental que únicamente admite dos estados posibles independientes: Verdadero (True) o Falso (False).

⚡ Evaluación

¿Qué pasaría si un sistema confunde un tipo de dato de texto con uno numérico e intenta multiplicarlos?

  • El software colapsará de inmediato debido a una incompatibilidad operacional.
  • La computadora aumentará de velocidad automáticamente.
  • El navegador web convertirá todo a código CSS.

¿Cuál es la diferencia fundamental entre una variable y una constante en la memoria RAM?

  • La constante pesa el doble que una variable normal.
  • El valor de la variable puede modificarse durante la ejecución; la constante permanece fija desde el principio.
  • Las constantes solo sirven para guardar texto y las variables para números enteros.

Si guardamos el valor de la temperatura de un reactor espacial como "36.6 °C", ¿qué tipo de dato numérico se está empleando?

  • Entero.
  • Booleano.
  • Real o Flotante.

¿Cuáles son los dos únicos estados lógicos válidos admitidos por un tipo de dato Booleano?

  • Verdadero (True) o Falso (False).
  • Positivo, Negativo o Neutro.
  • Inicio o Fin del algoritmo.

Para almacenar la cantidad exacta de alumnos inscritos en la especialidad de programación (por ejemplo, 512), ¿qué tipo de dato es el ideal?

  • Flotante con decimales.
  • Entero.
  • Booleano condicional.

¿En qué lugar físico del hardware se apartan de forma temporal los casilleros de memoria para nuestras variables?

  • En el monitor de video de alta definición.
  • En el cable de la red escolar.
  • En la memoria de acceso aleatorio RAM.

¿Qué tipo de dato usarías para guardar la respuesta a la pregunta: "¿El estudiante completó la misión?"?

  • Booleano.
  • Entero sin signo.
  • Cadena de caracteres alfanuméricos extendidos.

Si declaramos una constante con el valor de Pi (3.1416), ¿qué significa esto para el resto del programa?

  • Que el usuario podrá cambiar el valor de Pi escribiendo en el teclado.
  • Que ninguna línea de instrucción posterior podrá reasignar o modificar ese valor en memoria.
  • Que la computadora lo borrará al llegar al bloque de salida.

¿Por qué es necesario definir los límites operacionales de los tipos de datos?

  • Para que el diseño CSS se adapte mejor a las pantallas móviles.
  • Para cambiar el color de las palabras reservadas en InfinityFree.
  • Para asegurar que el procesador sepa exactamente cuánta memoria ocupar y qué cálculos matemáticos son válidos.
