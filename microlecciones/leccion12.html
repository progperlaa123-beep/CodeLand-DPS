12. Instrucciones de Entrada y Salida de Datos

Los flujos de datos básicos permiten la interacción externa con el algoritmo. Una entrada captura información de sensores o teclados y una salida proyecta los cómputos procesados en interfaces visuales.

💡 Conceptos Clave y Definiciones Académicas:

  • Entrada (Leer / Input): Comando técnico encargado de pausar el programa temporalmente para capturar un dato desde el exterior y guardarlo inmediatamente dentro de una variable.
  • Salida (Escribir / Print): Operación que despliega datos explícitos, textos literales o el contenido actual de una variable en la consola del sistema.
  • Flujo Secuencial Exclusivo: En pseudocódigo, ninguna operación matemática puede procesar un dato de entrada si la instrucción 'Leer' no fue ejecutada con anterioridad cronológica.

📝 Evaluación

Demuestra tu dominio técnico sobre instrucciones de Entrada y Salida:

¿Cuál es el propósito medular de la instrucción 'Leer' en pseudocódigo?

  • Mostrar el resultado de una suma en pantalla.
  • Pausar el sistema para recibir un dato externo del usuario y guardarlo en una variable.
  • Borrar la memoria caché del navegador de manera definitiva.
❌ Incorrecto. 'Leer' captura información del usuario hacia el interior de la computadora.

¿Qué instrucción técnica se utiliza formalmente para proyectar información hacia el exterior?

  • Escribir (o Imprimir)
  • Capturar
  • DefinirEstructura
❌ Incorrecto. 'Escribir' saca los datos procesados y los muestra visualmente.

Si ejecutas `Escribir "Hola ", nombre` donde `nombre` vale "Sofía", ¿cuál es el resultado preciso?

  • Se imprime el texto literal: "Hola nombre".
  • El programa marca un error grave de sintaxis matemática.
  • Se concatena y muestra en pantalla: "Hola Sofía".
❌ Incorrecto. Al colocar una variable sin comillas, se accede y concatena su valor dinámico.

¿Qué ocurre si intentas procesar un cálculo aritmético con una variable que nunca pasó por una instrucción de 'Leer' ni de asignación?

  • El procesador inventa un número mágico al azar.
  • El algoritmo falla o devuelve un valor nulo/indefinido por falta de datos iniciales.
  • El programa funciona perfectamente ignorando esa operación.
❌ Incorrecto. Operar con variables vacías rompe la consistencia lógica del programa.

En un diagrama de flujo estándar, ¿qué figura representa de forma universal la entrada de datos por teclado?

  • Un paralelogramo (romboide).
  • Un círculo perfecto de conexión.
  • Un rombo de decisión lógica.
❌ Incorrecto. El paralelogramo es el símbolo internacionalmente aceptado para operaciones I/O en diagramas.

¿Para qué se utilizan las comillas dobles `""` dentro de una instrucción 'Escribir'?

  • Para indicarle a la computadora que multiplique ese renglón.
  • Para esconder el código del usuario final.
  • Para definir cadenas de texto explícitas y mensajes literales.
❌ Incorrecto. El texto entre comillas se muestra de forma idéntica y literal en pantalla.

Si un programa solicita la edad del usuario, ¿qué línea es sintácticamente correcta?

  • Leer edad
  • Escribir edad del usuario por teclado
  • Leer "edad"
❌ Incorrecto. 'Leer' debe ser acompañado directamente por el identificador de la variable sin comillas.

¿Cuál es el canal periférico de entrada por defecto más común en los sistemas computacionales académicos?

  • La impresora láser.
  • El teclado.
  • Las bocinas del sistema.
❌ Incorrecto. El teclado procesa y captura la entrada estándar de texto y números.

¿Qué beneficio tiene anteponer un 'Escribir' explicativo antes de un 'Leer'?

  • Guiar al usuario humano para saber exactamente qué dato debe ingresar.
  • Hacer que la computadora consuma menos memoria RAM de forma drástica.
  • Es obligatorio, el pseudocódigo no compila si no hay un mensaje explicativo previo.
❌ Incorrecto. No es obligatorio por compilación, pero es una norma de usabilidad imprescindible.

Si en la consola ves el mensaje "Ingresa tu año:" y la ejecución se congela con un cursor parpadeante, el sistema está ejecutando:

  • Un bucle infinito destructivo.
  • Un comando de cierre de sesión.
  • Una instrucción de Entrada de datos ('Leer').
❌ Incorrecto. El sistema detiene el flujo secuencial en espera de que presiones Enter tras digitar tu dato.
