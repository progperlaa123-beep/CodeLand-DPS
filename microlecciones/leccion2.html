2. ¿Qué es un Algoritmo?

En el corazón de la informática y la programación estructurada se encuentra el concepto de algoritmo. Un algoritmo no es código de computadora ni un lenguaje en específico; es una abstracción lógica previa. Se define como un método sistemático y estructurado para resolver un problema paso a paso, sirviendo como el mapa conceptual que posteriormente se traducirá a cualquier lenguaje de programación.

💡 Conceptos Clave y Definiciones Académicas:

  • Definición de Algoritmo: Conjunto finito, ordenado y secuencial de instrucciones o reglas perfectamente definidas que guían la resolución de un problema, garantizando que, a partir de un estado inicial, siempre se alcance el mismo resultado final (Joyanes Aguilar, 2013).
  • Finitud: Característica indispensable que establece que el algoritmo debe terminar obligatoriamente en algún momento, ejecutando un número limitado de pasos (Sznajdleder, 2012).
  • Definición (Univocidad): Los pasos deben ser completamente claros y exactos. Si se sigue el algoritmo dos o más veces con los mismos datos de entrada, se debe obtener rigurosamente el mismo resultado.
  • Estructura Básica: Todo algoritmo se compone formalmente de tres etapas sucesivas: Entrada (datos iniciales), Proceso (cálculos y lógica) y Salida (los resultados obtenidos).

⚡ Evaluación

Desde una perspectiva académica y técnica, ¿qué es fundamentalmente un algoritmo?

  • Un cableado físico dentro del procesador de la computadora.
  • Una pantalla de interfaz gráfica diseñada con estilos CSS avanzados.
  • Un método lógico, finito y ordenado de pasos para resolver un problema independiente del lenguaje.

Si un conjunto de instrucciones lógicas se ejecuta indefinidamente sin parar, rompe con el criterio de:

  • Finitud.
  • Modularidad.
  • Abstracción.

¿Cuáles son las tres etapas fundamentales que estructuran el flujo de información dentro de cualquier algoritmo?

  • Inicio, Computadora e Internet.
  • Entrada de datos, Proceso de transformación y Salida de resultados.
  • Diseño gráfico, Animación y Base de datos.

Según el ejemplo de Spotify, ¿qué actúa como "Entrada" en su algoritmo de recomendación?

  • Los altavoces o audífonos del usuario.
  • Las canciones escuchadas previamente y los patrones del usuario.
  • El pago de la suscripción premium mensual.

¿Qué significa la propiedad de "Univocidad o Definición" en un algoritmo académico?

  • Que al seguirlo varias veces con los mismos datos de entrada, siempre se obtiene el mismo resultado.
  • Que las instrucciones solo se pueden ejecutar una vez en la vida de la CPU.
  • Que el algoritmo obligatoriamente debe estar en idioma inglés.

¿Cuál es la relación real entre un algoritmo y un lenguaje de programación específico?

  • El algoritmo solo funciona si se escribe directamente en código binario pura.
  • Cada lenguaje requiere reinventar la lógica del algoritmo desde cero.
  • El algoritmo es una abstracción lógica previa; es un mapa independiente de cualquier lenguaje.

¿Qué autor define al algoritmo como un conjunto de reglas que garantizan alcanzar el mismo resultado a partir de un estado inicial?

  • Sznajdleder (2012).
  • Joyanes Aguilar (2013).
  • Vimeo Developers.

Si una aplicación musical se congela por culpa de un bucle sin fin, ¿qué propiedad matemática falló?

  • La finitud del algoritmo, al no poseer un número limitado de pasos.
  • La velocidad del ancho de banda del internet escolar.
  • El diseño visual de la interfaz de usuario.

En la definición técnica de un algoritmo, ¿qué significa que los pasos sean "ordenados y secuenciales"?

  • Que se pueden ejecutar al azar o en desorden según lo decida la computadora.
  • Que las operaciones matemáticas más difíciles se hacen siempre al final.
  • Que llevan una línea de ejecución estricta, donde un paso depende del anterior.

¿Cuál es el objetivo final de estructurar la abstracción de un problema en un algoritmo?

  • Tener un mapa conceptual claro que sirva para traducirse eficientemente a código.
  • Incrementar el uso de almacenamiento físico en el servidor de base de datos.
  • Evitar que los programadores tengan que usar la lógica mental.
