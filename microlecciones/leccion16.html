16. Condicionales Anidadas y Selección Múltiple

Cuando un problem lógico presenta más de dos opciones de solución mutuamente excluyentes, las estructuras condicionales simples o compuestas resultan insuficientes o ineficientes por sí solas, haciendo necesario el uso de la anidación o de selectores dedicados.

💡 Conceptos Clave y Definiciones Académicas:

  • Anidamiento de Condicionales: Consiste en incrustar una estructura `Si-Entonces-Sino` dentro de otra estructura condicional previamente abierta (Sznajdleder, 2012). Permite evaluar encadenamientos lógicos profundos.
  • Estructura de Selección Múltiple (Según Sea / Switch): Variante sintáctica optimizada que evalúa una única variable selectora (generalmente numérica o de tipo carácter) y desvía el flujo directamente hacia la etiqueta o caso coincidente, ahorrando múltiples evaluaciones booleanas repetitivas.

⚡ Evaluación

¿Qué es técnicamente una condicional anidada en el paradigma de la programación estructurada?

  • Un bucle iterativo que se repite hasta que el usuario ingresa un dato numérico.
  • Una estructura condicional colocada dentro del bloque de instrucciones de otra estructura condicional previa.
  • Un error sintáctico provocado por no cerrar la palabra reservada 'FinSi'.

¿Cuándo es académicamente más recomendable utilizar una estructura de Selección Múltiple (`Según Sea` / `Switch`) en lugar de condicionales anidadas?

  • Cuando se requiere comparar una sola variable contra múltiples valores específicos puntuales y excluyentes.
  • Cuando se necesitan evaluar rangos aritméticos complejos con operadores relacionales mixtos (`<`, `>`, `AND`).
  • Cuando el programa no tiene variables de entrada definidas.

De acuerdo con Sznajdleder (2012), ¿qué nos permite realizar el anidamiento de condicionales?

  • Saltarse de forma directa el cierre de las instrucciones principales.
  • Ejecutar el código sin necesidad de declarar variables lógicas.
  • Permite evaluar encadenamientos lógicos profundos al incrustar un `Si-Entonces-Sino` dentro de otro.

¿Cuál es el principal beneficio de rendimiento de una estructura "Según Sea" (Switch) en comparación con múltiples condicionales independientes?

  • Optimiza el rendimiento ahorrando múltiples evaluaciones booleanas repetitivas al desviar el flujo directamente al caso coincidente.
  • Permite que el procesador gaste el doble de energía RAM.
  • Hace que las fuentes de texto de la interfaz cambien automáticamente de color.

En el ejemplo del control del personaje de un videojuego, ¿por qué es ineficiente usar condicionales simples consecutivas?

  • Porque el personaje se moverá en diagonal aunque no se lo pidamos.
  • Porque desactiva la lectura de periféricos inalámbricos.
  • Porque obligaría a la máquina a procesar preguntas y comprobaciones innecesarias después de haber encontrado la dirección correcta.

¿Qué tipos de datos evalúa preferentemente una variable selectora en una estructura de selección múltiple según el texto?

  • Expresiones algebraicas complejas y vectores multidimensionales.
  • Generalmente variables de tipo numérico o de tipo carácter.
  • Conexiones a bases de datos remotas únicamente.

¿Cuándo se determina que las opciones de solución de un algoritmo son "mutuamente excluyentes"?

  • Cuando al cumplirse una opción, las demás quedan descartadas por completo para esa ejecución.
  • Cuando todas las condiciones se ejecutan al mismo tiempo de forma obligatoria.
  • Cuando ninguna de las opciones da una respuesta válida al sistema.

Si un problema lógico presenta más de dos opciones de solución mutuamente excluyentes, ¿qué ocurre con las condicionales simples o compuestas por sí solas?

  • Detienen la ejecución del hardware de inmediato.
  • Se vuelven infinitas consumiendo la memoria caché.
  • Resultan insuficientes o ineficientes por sí solas.

¿Qué término define la acción de incrustar una estructura de decisión completa dentro de otra previamente abierta?

  • Bucle compuesto.
  • Anidamiento (o anidación).
  • Bifurcación secuencial.

En una estructura `Según Sea`, la variable que define el rumbo del flujo lógico se denomina académicamente como:

  • Variable selectora.
  • Contador booleano.
  • Acumulador estático.
