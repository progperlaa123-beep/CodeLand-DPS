21. Variables de Control Especiales: Contadores, Acumuladores y Banderas

En la programación iterativa y lógica, existen variables encargadas de rastrear el estado interno, realizar conteos específicos o acumular resultados parciales producidos dentro de las estructuras cíclicas.

💡 Conceptos Clave y Definiciones Académicas:

  • Contador: Es una variable entera cuyo valor se incrementa o decrementa en una cantidad constante (habitualmente de uno en uno) en cada repetición de un bucle. Se representa típicamente como `c <- c + 1`.
  • Acumulador o Sumador: Es una variable que almacena sumas sucesivas de valores variables. A diferencia del contador, el incremento no es constante sino variable (ej. `suma <- suma + gasto_cliente`).
  • Bandera (Flag / Interruptor): Es una variable lógica (booleana) que registra si ha ocurrido o no un evento determinado dentro del programa. Solo puede tomar dos estados: Verdadero o Falso (`verdadero` / `falso`).
  • Inicialización Obligatoria: Antes de entrar a un ciclo, los contadores y acumuladores deben limpiarse o inicializarse (comúnmente en 0) para evitar arrastrar basura de memoria.

⚡ Evaluación

¿Cuál es la función principal de una variable de tipo Contador?

  • Incrementar o decrementar su valor en una cantidad constante en cada ciclo.
  • Sumar valores completamente variables ingresados por el usuario.
  • Cambiar entre cadenas de texto largas de forma automática.

¿Qué caracteriza a un Acumulador a diferencia de un Contador?

  • Que su incremento siempre es exactamente igual a 1.
  • Que su incremento o valor sumado varía en cada iteración.
  • Que solo puede almacenar valores lógicos verdaderos o falsos.

¿Qué tipo de valor almacena una variable tipo Bandera (Flag)?

  • Números decimales de alta precisión.
  • Estructuras completas de diagramas de flujo.
  • Valores lógicos booleanos (Verdadero o Falso).

¿Por qué es obligatorio inicializar los contadores y acumuladores antes de iniciar un bucle?

  • Para establecer un punto de partida limpio y evitar datos basura en memoria.
  • Porque si no se hace, el código HTML se destruye automáticamente.
  • Para permitir que las variables se conviertan en arreglos multidimensionales.

¿Cuál de las siguientes líneas de código representa la sintaxis correcta de un contador?

  • acumulador <- acumulador + precio_articulo
  • contador <- contador + 1
  • bandera <- Verdadero

¿Cuál de las siguientes líneas representa de forma idónea la acción de un acumulador de sueldos?

  • sueldo <- 1500
  • total_sueldos <- total_sueldos + 1
  • total_sueldos <- total_sueldos + sueldo_empleado

En el contexto de aplicación real del auto eléctrico, ¿qué elemento opera como la Bandera?

  • El indicador luminoso que evalúa si el sistema tiene energía o una falla crítica.
  • La suma de los kilovatios consumidos por todos los autos.
  • El número total de vehículos que ingresaron uno a uno.

Si una bandera cambia su estado a Falso dentro del ciclo, ¿para qué se suele usar esta alteración?

  • Para borrar el registro del tiempo transcurrido en la base de datos.
  • Como señal o condición para romper o terminar la ejecución del bucle.
  • Para multiplicar por cero todos los acumuladores activos.

Si inicializas un contador en 10 y en cada vuelta ejecutas `c <- c - 1`, ¿qué tipo de conteo realizas?

  • Un conteo regresivo o decremento constante.
  • Un proceso de acumulación exponencial variable.
  • Un bucle infinito indeterminado por bandera de texto.

¿Qué ocurriría si un acumulador dentro de un bucle repite su ciclo pero no fue inicializado externamente?

  • El compilador calcula de forma inteligente el promedio exacto automáticamente.
  • El navegador web bloquea el archivo php del mapa de misiones.
  • Puede producir un error de ejecución o arrojar un total alterado debido a la falta de un valor base certero.
